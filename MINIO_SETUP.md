# Почему не грузятся картинки из Minio

## 1. Сделай бакет `test` публичным на чтение

По умолчанию Minio **не отдаёт** файлы анонимно — браузер получает **403 Forbidden**.

**Что сделать:**

1. Открой **http://localhost:9001** → войди (minio / minio124).
2. Слева выбери **Buckets** → открой бакет **test**.
3. Открой вкладку **Access** (или **Manage** / **Access Policy**).
4. Поставь политику доступа **Public** (публичное чтение для всех), либо добавь policy:
   - **Access**: `public` или вручную policy с `GetObject` для `*`.

В новых версиях Minio: зайди в бакет **test** → сверху или сбоку **Access** / **Anonymous** → включи **Read only** (или выбери готовую политику **public**).

После этого запросы вида `http://localhost:9000/test/li_ion.jpg` из браузера начнут отдавать картинку.

---

## 2. Проверка по шагам

| Проверка | Как |
|----------|-----|
| Minio запущен | `docker ps` — есть контейнер с портами 9000, 9001 |
| Бакет и файлы | http://localhost:9001 → Buckets → test → внутри 6 файлов: li_ion.jpg, li_ion.mp4, li_po.jpg, li_po.mp4, ni_mh.jpg, ni_mh.mp4 |
| Политика бакета | У бакета **test** включён публичный доступ на чтение (см. выше) |
| URL вручную | В браузере открой **http://localhost:9000/test/li_ion.jpg** — должна открыться картинка (или скачаться). Если 403 — значит политика ещё не публичная |
| Приложение | Запущено из корня проекта: `go run cmd/awesomeProject/main.go`, в браузере http://localhost:8080 |

---

## 3. Имена файлов (должны совпадать)

В бакете **test** объекты должны называться **ровно так** (латиница):

- li_ion.jpg  
- li_ion.mp4  
- li_po.jpg  
- li_po.mp4  
- ni_mh.jpg  
- ni_mh.mp4  

Если переименовывал в Minio — проверь, что нет лишних пробелов и расширение точное (.jpg, .mp4).
